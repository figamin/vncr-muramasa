🧹 Message Filters

Replaces configured words/phrases in user messages, deletes the original, and reposts the cleaned text under the author (via a webhook). Originals are recorded below and to the mod-log channel. Rules apply in all channels except members holding an excluded role. Edits here go live within one message, no restart needed.

The bot needs Manage Webhooks and Manage Messages in filtered channels.

Settings

Filter enabled is the master switch: when off, no messages are touched no matter what rules exist.
Mod-log channel is where each original (pre-filter) message is posted so moderators can review it. Leave it on (none) to keep only the in-page log at the bottom of this tab.

Add Rule

What each field does
  • Pattern: the text to look for in a message.
  • Replacement: what each match is turned into. Leave it empty to delete the matched text entirely.
  • Simple word: matches the literal text you typed.
  • Regex: treats the pattern as a regular expression (advanced). Capture groups like \1 work in the replacement. The whole-word and match-plurals options do not apply in regex mode.
  • ignore case: match regardless of capitalization (Cat = cat = CAT).
  • whole word: only match the word on its own, not inside a bigger word (cat matches "a cat" but not "category" or "cats"). Simple mode only. Leave it OFF for Japanese/CJK words, where it usually prevents any match.
  • match plurals: also match the plural form (cat also matches cats, box also matches boxes). Both forms use the same replacement. Simple mode only.

Excluded Roles

Members holding any role listed here are never filtered (their messages are left alone even if they match a rule). Useful for moderators or trusted members. If a member has multiple roles, having just one excluded role is enough to exempt them.

Excluded Channels

In channels listed here the whole pipeline is skipped: no word-filtering/deletion and no media reposting/flagging. This list is shared with the Media Flags feature. Threads inherit their parent channel's exclusion.

🚩 Media Flags

Reposts non-exempt members' images/GIFs/videos with ✅/🚩 buttons anyone can click; every 🚩 flag posts a heads-up to the mod-logs channel naming who flagged it. Log-only.

Settings

Media flags enabled is the master switch: when off, no media is reposted or reviewed.
Mod-log channel is where a heads-up (naming the flagger) is posted for every 🚩 flag. Leave it on (none) to keep only the in-page log at the bottom of this tab.
Excluded channels (channels where media is not reposted/flagged) are shared with the word filter and managed in the Message Filters tab.

Excluded poster roles

Media from members holding any role listed here isn't reposted or reviewed.

Ignored flagger roles

Flags from members holding any role listed here are ignored (no mod-log heads-up).

Opted-out members

Media from these members isn't reposted or reviewed. Members can add and remove themselves with /filter; adding someone here does the same thing. The word filter is unaffected: a message with a filtered word is still cleaned and reposted.

🧹 Message Purge

Mass-deletes matching messages via Discord's search, deleting and re-searching continuously so a single run clears the whole set (no result-size limit). This is irreversible. A quick estimate + preview must be confirmed before anything is deleted. You can leave this page and return; deletion keeps running. Only one purge runs at a time. (Regex and directed-at filters fall back to a slower full history scan.)

Target & filters

Dates are UTC, taken as 00:00 that day (so Before a date excludes that whole day). Directed-at and regex use a slower full history scan (not the fast ID search); scope them to a channel or a target user when you can.
These two apply to private threads only; public threads are normal visible content and are always purged message-by-message. A private thread is searchable only by its members, so a user's own bot/quiz thread can hold thousands of messages nobody else can see, and clearing them one at a time spends the whole delete budget on invisible content. Deleting such a thread takes a single call, but it also removes anyone else's messages inside it.

🔀 Transfer User (Hikaru)

×

Moves reading logs, votes and nominations from an old account to a new one, across every server. Nothing is deleted: rows that collide with the new account's own records (the same VN in the same month, a ballot in the same cycle, a nomination for the same server and period) stay on the old account and are listed. Manager grants and the username cache are not moved. A snapshot is saved before every change, and each transfer can be undone from the list below.
